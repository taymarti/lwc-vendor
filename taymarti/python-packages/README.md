# taymarti/python-packages

Python wheels we build, for environments that can't build them: candidates are `dh-chart-ext` (dh-charts
`dh-plugin/`, with its JS bundle) and the fork's `deephaven-plugin-tradingview-lightweight` (`0.1.0+acme.1`).
None are published here yet; until then build them from source (dh-charts README, "The fork").
Every version stays: a new release adds a wheel, never replaces one. Hashes (SHA-256) go in `INTEGRITY`.
